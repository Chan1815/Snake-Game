#  Snake Game (Slither-Style)

A simple browser-based Snake (Slither-style) game built using **HTML, CSS, and JavaScript**.  
The game includes real-time controls, collision detection, scoring, and a persistent high-score feature.

---

## 🚀 Features
- Keyboard-controlled snake movement  
- Random food generation  
- Collision detection with walls and snake body  
- Live score display  
- High score saved using browser localStorage  

---

## 🛠 Technologies Used
- HTML5  
- CSS3  
- JavaScript  
- Canvas API  

---

## ▶ How to Run the Game
1. Download or clone this repository  
2. Open `index.html` in any modern web browser  
3. Use **arrow keys** to control the snake  

---

## 🎯 Project Purpose
This project was developed to practice JavaScript fundamentals, DOM manipulation, and basic game logic, and to showcase frontend development skills.
